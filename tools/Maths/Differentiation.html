📘 අවකලනය (Differentiation)

G.C.E. Advanced Level Combined Mathematics

1. මූලික අවකලන සූත්‍ර

d/dx (xⁿ) = nxⁿ⁻¹
d/dx (c) = 0
d/dx (eˣ) = eˣ
d/dx (ln x) = 1/x

2. ත්‍රිකෝණමිතික ශ්‍රිත

d/dx(sin x) = cos x
d/dx(cos x) = −sin x
d/dx(tan x) = sec²x
d/dx(cot x) = −cosec²x

3. Product Rule

d/dx(uv) = u(dv/dx) + v(du/dx)

4. Quotient Rule

d/dx(u/v) = [v(du/dx) − u(dv/dx)] / v²

5. Chain Rule

dy/dx = dy/du × du/dx

6. උදාහරණය

y = x³ + 4x² − 5x + 2

dy/dx = 3x² + 8x − 5

7. ස්පර්ශකයේ බෑවුම

Gradient = dy/dx

යම් ලක්ෂ්‍යයකදී වක්‍රයේ ස්පර්ශකයේ බෑවුම සොයා ගැනීමට එම ලක්ෂ්‍යයේදී dy/dx හි අගය ලබා ගනී.
