1. මූලික අනුකලන සූත්‍ර

∫1 dx = x + C
∫eˣ dx = eˣ + C
∫1/x dx = ln|x| + C

∫sin x dx = −cos x + C
∫cos x dx = sin x + C
∫sec²x dx = tan x + C
∫cosec²x dx = −cot x + C
