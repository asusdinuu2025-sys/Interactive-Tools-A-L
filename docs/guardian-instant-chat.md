# Guardian instant chat
Ordinary text and replies are shown immediately in a sender-only local outbox. A bounded serial queue retains the existing send rate limit and calls Guardian before the actual public INSERT. Failed entries can be revised or dismissed; no automatic retries of unknown writes. Pending messages are not persistent across page reloads and not published via Presence/Realtime. Existing attachment uploads and edits keep the strict flow. Social is unchanged. Admin mode preference is stored separately and read at startup/reopening; preview preference is local-only. If the preference RPC is unavailable, clients default to instant presentation while still requiring existing database moderation. No changes to AI permits, word filters or other authorization.
