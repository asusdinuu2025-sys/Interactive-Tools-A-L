# Guardian live text release
Default off during deployment. The admin master and AI toggles are database-backed. Public chat, Social posts and comments use an authenticated preflight; the database requires a one-use exact-text permit when AI is enabled. Permits expire in three minutes. No student text is retained by Guardian in its own audit log, which records only time, surface and reason for AI blocks. Metadata older than 30 days is excluded and pruned on future decisions. Provider failure rejects the write rather than bypassing the check. First-use notice explains external processing. No student image or file is sent to the provider. Image moderation, URL reputation, review queue and automatic penalties are not implemented. Existing moderation/report controls remain. Users may edit flagged text or contact moderators. Enable only after main deployment is verified. Roll back by turning master switch off. The deterministic rules do not guarantee link safety and count retained recent rows; this is not a durable spam quota.
