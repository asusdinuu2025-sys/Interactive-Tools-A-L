# Custom word filter preview
Admin > Bot Management > Custom word filter. Enter one term or phrase per line, toggle the independent module and save. Preview saves locally; production uses the admin-only RPC. Matching is ASCII-case-insensitive and NFC-normalized, using whole Latin/Sinhala words and punctuation-separated phrases. No regex input; no automatic list or AI retraining. Additive trigger checks new or edited text on all three surfaces, respecting master and area switches even when AI is off. It rejects matching writes; does not store rejected text, scan media, detect every evasion, or alter historical messages. Apply SQL only after tests and owner approval; defaults OFF. Existing Guardian settings and APIs unchanged. If SQL is not installed, production card shows unavailable and existing controls continue. Rollback: disable module or drop only three guardian_00_words_* triggers.
